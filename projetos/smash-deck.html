01 Produto autoral · SPA sem framework

Uma IP completa: do worldbuilding criativo à engenharia front-end.

Jogo de cartas autoral criado do zero: game design, lore, 103 lendas e o site oficial que coloca tudo isso no navegador.

Ver o site Ver o código

De vitrine a ferramenta. Na primeira versão, achar uma carta entre 103 era rolar a página inteira. Agora dá para filtrar por classe, buscar pelo nome e ordenar por atributo, e a busca fica salva no link.

O quê

O desafio foi dar vida a um produto digital denso que criei do absoluto zero. Fui além do código: assumi o game design, as mecânicas de duelo e todo o worldbuilding, incluindo a escrita do livro de lore "Crônicas do Confluente" e um manual de 36 páginas. Materializei tudo isso em um site oficial com UI limpa que traduz regras complexas, fichas ricas para as 103 lendas (com histórias e falas próprias) e até prototipação do produto físico (Deck Box).

Para quem

Para o usuário que busca explorar um universo criativo em uma experiência fluida e mobile-first, e para recrutadores que precisam validar minha capacidade de unir visão de produto de ponta a ponta com arquitetura de software robusta.

Como

SPA em JavaScript puro, HTML e CSS, com zero frameworks. A engenharia por trás é estritamente orientada a dados e modular: cada tela nasce dos mesmos componentes, e as 103 cartas são renderizadas dinamicamente a partir de uma única fonte de dados (objetos ES6). A navegação entre catálogo, lore e regras ocorre de forma nativa e instantânea.

Por quê

Para provar que o domínio dos fundamentos permite escalar qualquer ideia. A separação entre dados e interface garante a performance, enquanto a conversão de artes visuais pesadas para WebP mantém o site rápido.

  • 103lendas geradas a partir de uma única função
  • 29,5 → 10,2 MBde peso de imagens, após otimização

“O que mais me orgulha foi ver um universo inteiro criado por mim sair do papel e se tornar uma aplicação tangível. Eu não apenas escrevi o código: eu criei a mitologia, desenhei as mecânicas de duelo, estruturei a narrativa de 103 personagens e traduzi essa complexidade em uma interface limpa e intuitiva. Ver o esforço lógico do JavaScript dar vida a algo tão autoral provou para mim que sei fundir criatividade extrema com engenharia de software.”
